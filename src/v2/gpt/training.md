## Weekly Structure

Strength supports the running plan. The hierarchy changes by phase, but the Thursday no-running rule stays constant.

### Phase 1 - Post-HM Recovery (Mar 30 - Apr 12)

**Week 1:** Rest Mon-Wed, then 3 easy runs of 4-5 km. One light full-body session mid-week only if soreness is low. RPE 5-6.

**Week 2:** Resume 3 sessions with conservative hypertrophy loading.

| --- | ------------------- | ----------------------------- | ------------------------ |
| Mon | Rest or easy 4-5 km | --                            | Week 1 can be full rest  |
| Tue | Easy 4-5 km         | Light full-body or Upper Push | Only if recovery is good |
| Wed | Easy 4-5 km         | --                            |                          |
| Thu | Rest from running   | Legs light                    | Keep Thursday rule       |
| Fri | Easy 5-6 km         | Upper Pull optional           | Week 2 only              |
| Sat | Rest                | --                            |                          |
| Sun | Easy 6-7 km         | --                            | No quality work          |

## Double-Day Guidelines

When running and lifting land on the same day:

- Minimum 6-8 hour gap between sessions.
- Run first, lift second.
- Post-run shake immediately, then full meal before PM lift.
- If energy is low for the PM lift, reduce volume by one set per exercise. Do not skip by default.
- Thursday is always REST from running. Legs stay on Thursday in all phases except Phase 6 weeks 6-8.

## Strength Training Focus

### Cut Phases (Apr 13 - Aug 30)

- Hypertrophy focus: 3-4x8-12 reps
- Double progression: hit top of rep range -> +2.5 kg -> reset to bottom
- RPE 7-8 max
- If a lift regresses >10% for 2 sessions, drop from 4 sets to 3 and keep the weight
- If RPE is consistently 9+, reduce weight 5% and reassess deficit depth

### Peak Phase (Sep 1 - Oct 25)

- Weeks 1-5: full hypertrophy, progressive overload
- Weeks 6-7: push + pull only, no legs
- Week 8: 1 light upper pump session, RPE 5

## Recovery & Monitoring

- Strength drops >10% for 2 sessions -> reduce from 4 sets to 3
- Easy-run HR elevated 5+ bpm for 3 runs -> add rest day
- Garmin Sleep Score <60 for 2 nights -> skip quality session
- RHR elevated 5+ bpm over baseline -> reduce volume 20%
- HRV drops >15% from 7-day average -> optional rest day
- Body Battery <30 at wake -> full rest day
- Fewer than 2 strength sessions for 2 straight weeks -> mandatory reduced-volume 2x20 min full-body minimum

4. Dips - 3x8-12

7. Core anti-rotation or flexion - 3 sets

3. Row accessory - 3x10-12
4. Face pulls - 3x15-20
5. Curl variation - 3x10-12

7. Carry or stability - 3 sets

## Optional: Arms and Shoulders (4th Session, Sat PM)

**When:** Cut Blocks 1 and 2 only. Drop if body battery <60 at wake or soreness lingers.

1. Lateral Raises - 3x15
2. Rear Delt Flyes - 3x15
3. Barbell Curls - 3x10-12
4. Tricep Pushdowns - 3x12-15
5. Hammer Curls - 2x12

**Total:** ~13 sets, 25-30 min, RPE 6-7.

## Tracking Rules

- Log every working weight.
- If a PT session uses different exercises, still log the loads.
- No logged weights means no progression decisions.
