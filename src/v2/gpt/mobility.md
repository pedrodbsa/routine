# MOBILITY AND PREHAB PROTOCOL - GPT V2

## Purpose

Desk work, age, running volume, and caloric deficit all increase the cost of skipping mobility. This protocol stays mandatory across every phase.

## Daily Mobility Routine (10 min)

1. Half-Kneeling Hip Flexor Stretch - 60s/side
2. 90/90 Hip Switches - 60s total
3. Open Book Rotations - 30s/side
4. Cat-Cow - 60s
5. Thread the Needle - 30s/side
6. Wall Ankle Dorsiflexion - 45s/side
7. Calf Raises with Pause - 30s
8. World's Greatest Stretch - 30s/side
9. Standing Hamstring Sweep - 30s/side

## Post-Run Cool-Down (5 min)

1. Easy walk - 2-3 min
2. Standing quad stretch - 30s/side
3. Standing calf stretch - 30s/side
4. Forward fold - 30s
5. Deep breathing - 5 slow breaths

## Cut-Phase Recovery Emphasis (Apr 13 - Aug 30)

During caloric deficit, connective-tissue recovery is slower. Mobility compliance matters more, not less.

- Foam rolling is mandatory post-run during cut phases.
- Add 2 minutes of 90/90 switches after any double day.
- If morning mobility is skipped, do the hip flexor + hamstring sequence before bed.

## Desk Worker Mini-Breaks (2 min, every 60-90 min)

1. Stand + hip circles - 20s
2. Shoulder dislocates - 10 reps
3. Standing hip flexor stretch - 20s/side
4. Neck circles - 10s each direction

## Injury and Pain Tracking

Track in the daily Status table:

`| Pain/Tightness | None / [location] [severity 1-5] |`

### Severity Scale

- 1 = awareness only
- 2 = mild tightness, disappears when warm
- 3 = noticeable during activity, no gait change
- 4 = alters movement pattern
- 5 = cannot perform activity

### Rules

- Severity 1-2: train normally, note it
- Severity 3: reduce volume 30%, avoid aggravating movement
- Severity 4+: rest that pattern and substitute non-aggravating work
- Same location at severity 3+ for 3 straight days: see physiotherapist

**Cut-phase pain escalation:** During Phases 2, 4, and 5, any severity 3+ triggers an immediate calorie bump to maintenance (2,300) for that day plus the following day. Report it in the weekly review.
