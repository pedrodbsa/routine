On the morning plan for 2026-10-13, which had an easy run alone, the athlete replied: "A day with an easy run seems like a waste. We decide that we either have a quality session or an easy with a lift." The rule: **every training day is a quality session, or an easy run plus a lift.** A standalone easy run is not an acceptable day.

**Why:** an easy run alone costs a day's recovery budget and a gym-free slot for little stimulus; the athlete would rather stack the easy run with a lift (the pre-lunch double he already prefers, [[feedback-treadmill-run-backtoback-with-lift]]) and keep the other days for rest or quality. Body composition ranks first, so lifts are the scarce slot ([[project-objective-athletic-summer-2027]]).

**How to apply:** when building a week, pair each easy run with one of the three lifts (Chest + biceps, Back + triceps, Legs + shoulders); an easy run with no lift available is dropped, which makes the **bonus run the first thing to go** (it already is in the drop order, [[feedback-run-over-legs-legs-bulky]]). Quality days carry no lift. The long run stays alone (the coach's reading, not yet confirmed). Cost to flag each week: with 3 lifts and one quality, only 2 easy runs fit, so the week is ~31-32 km, right at the 30 km floor with no slack. If a week cannot hold 4 runs under the rule, say so rather than quietly adding a lone easy run.
