**Saturday is a standing rest day** (athlete-stated 2026-08-05, verified against Garmin: five consecutive rest Saturdays Jul 4 / Jul 11 / Jul 18 / Jul 25 / Aug 1). Before Jul 4 he did train Saturdays (Jun 13, 20, 27), so this is a settled recent habit rather than a lifelong rule — but it is the planning default now.

**Why:** the Phase 4-5 weekly template in `training.md` puts an easy 5-6 km run plus the standing arms/shoulders session in its Saturday column. That column is labelled a *reference layout*, not a constraint, but `/plan` kept regenerating Saturday sessions from it and the athlete had to correct it manually. Same failure class as [[feedback-rederive-not-inherit]] — a layout got treated as an agreement.

**How to apply:** plan Saturday as rest without asking. When a session needs rehoming, Saturday is not an available slot — check Wed/Thu/Fri/Sun instead. Note that removing Saturday collapses the week to five running days and two realistic strength slots, so the third lift (usually Legs) needs a Mon or Wed home or it slips; see [[feedback-strength-rotation-two-session-lookback]] for the rotation consequences. Athlete's preferred pairing is a run + lift in one gym trip ([[feedback-treadmill-run-backtoback-with-lift]]).
