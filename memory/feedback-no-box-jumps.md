The athlete does not want box jumps — specifically dislikes jumping *onto* a bench/box (2026-06-25). The leg-day explosive/plyo block stays (it's the running-economy stimulus), but program a ground-based or in-place variant instead.

**Why:** the box-jump landing mechanic (jumping up onto a raised surface) is the objection, not plyometrics per se. The explosive block's purpose — stiffness/elastic return for running economy, near-zero hypertrophy — is preserved by any crisp low-fatigue plyo.

**How to apply:** default the explosive slot to **light jump squats** (in place, land soft, reset). Alternatives if he wants variety/space: **broad jumps** (needs floor space) or **power A-skips 3×20 m** (needs a short runway). Never auto-prescribe box jumps. In Garmin these upload as `PLYO` / free-entry with the movement name in the step description (see [[feedback-garmin-onwatch-strength-loads]]). Jump squat is now a row in `strength-exercises.md`.
