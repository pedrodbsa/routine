Asked for the drop order on a compromised week (2026-09-29 consult), the athlete chose **run over Legs**: "prefer run over legs. my legs are quite bulky." The agreed order is **bonus run → strides → Legs → quality (to easy) → long run shortened to 10 km → Push and Pull merged**. The coach's proposal had Legs surviving longest (running-economy lift); the athlete overrode it.

Same session: **Legs was compressed to three core slots** — heavy primary lift, plyo block, hamstring insurance (~35 min). Single-leg and core slots are optional add-ons, never a reason to skip. The 6-slot version was delivered 5 times in 12 weeks.

The leg half now shares a session with shoulders ([[feedback-split-major-plus-minor]]); dropping Legs drops only the leg half, and the shoulder half still runs.

**Why:** the leg spec is already non-hypertrophy (heavy 4–6 reps, RIR 2–3, plyo, no calves — [[feedback-no-calf-training]], [[feedback-no-box-jumps]]), but the athlete's concern is size, and a session he sees as a bulk risk is a session that gets skipped. A short Legs he does beats a long one he does not.

**How to apply:** never argue Legs up the drop order; never re-expand it to six slots without being asked. When one slot is free, the quality run takes it over Legs. If the athlete ever asks why his legs are not getting stronger, the answer is the drop order he chose, and it should be said plainly.
