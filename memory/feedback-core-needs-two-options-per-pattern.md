description: Rotation rules cannot rotate a movement pattern that has only one gym-legal option — the slot gets dropped instead; keep ≥2 per core pattern
metadata:
  type: feedback
---

The athlete flagged 2026-08-10 that core selection lacked variation. He was right, and the cause
was structural rather than a shortage of imagination: of the four core patterns, **two had exactly
one G1-legal option each** — anti-extension was plank alone (the ab wheel has never been available
at G1) and dynamic flexion was cable crunch alone (both hanging variants need a bar, which is G2
only).

**Why:** the two-session rotation lookback cannot rotate a pattern with one option. The slot either
repeats — which the rotation rule is written to prevent — or gets dropped. It got dropped: the
70 kg cable-crunch load-up went unattempted through two consecutive Pushes (Aug 5, Aug 10) because
it was the only flexion option and it sat last in the order.

**How to apply:** when a rotation rule governs a slot, check the *filtered* pool for that gym
before programming, not the full library. Any pattern down to one legal option needs a second row
added or the rule silently degrades into skipping. Five rows were added to close this gap (barbell
rollout, long-lever/body-saw plank, reverse crunch, weighted bench sit-up, Copenhagen plank).

Select core by pattern, not novelty: for a 10K runner the transfer is in **anti-rotation and
anti-lateral-flexion** (pelvic drop and trunk rotation at footstrike), not flexion volume — a
third crunch variant is not variation that earns anything. Also put a twice-deferred load-up
early in the session order, never last. Related:
[[feedback-strength-rotation-two-session-lookback]], [[feedback-no-calf-training]].
