Dermatologist prescribed **isotretinoin** on 2026-06-25 for recurrent acne / folliculitis. The athlete takes **~5 mg/day, a microdose** (about 1/8–1/15 of a standard course), **at night with dinner**, his fattiest meal: absorption is fat-dependent. Never prescribe or log it "with breakfast" (a repeated `/plan` miscue, corrected 2026-07-15).

At this dose the cumulative total stays far below the ~120–150 mg/kg "durable remission" range, so it is ongoing control, not a cure; the problem may return if stopped. Course length and stop plan are still to be agreed with the dermatologist (`calendar.md` TODO).

**How to apply:**
- Training: musculoskeletal, CK and tendon effects are dose-dependent and negligible here. Do not attribute aches or fatigue to it.
- Bloods: baseline lipids/LFTs prudent, light-touch monitoring; alcohol days remain lipid/liver-relevant.
- Skin: dry lips, SPF for outdoor running, **no picking or extraction**. Skin anxiety is a known sleep disruptor ([[feedback-soft-markers-check-anxiety]]).
- Compatible with finasteride; the multivitamin's vitamin A is low-stakes at this dose.
- Re-read this if the dose goes up. Flag regimen changes in the `/report` skin block.
