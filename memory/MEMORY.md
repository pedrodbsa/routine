# Coaching Memory — MASTER

One line per memory. Protocols own the rules; these files hold the corrections, calibrations and preferences behind them.

## Critical lessons

- **Recovery markers are ground truth.** HRV, BB, RHR and stress decide readiness, not assumptions.
- **Never extend an easy-only block past one week on green markers, and when metrics decline under a plan, question the plan before asking for patience** (Feb 2026: three easy-only weeks on excellent markers regressed the HM prediction).
- **Garmin fitness age tracks scale BIA body fat** (its priority-1 component; vigorous minutes are already met) — context only, never a lever.
- **The athlete expects push-back.** Be critical, not passive; he trusts coaching autonomy.

## Training

- [Run over Legs; Legs compressed](feedback-run-over-legs-legs-bulky.md) — drop order bonus run → strides → Legs → quality → long → upper merged; Legs is the 3-slot ~35-min version
- [Strength tripwire rejected](feedback-strength-tripwire-rejected.md) — 3/3 Legs/Pull/Push written, delivery flagged only, never auto-downshifted; show commitment and delivered count side by side
- [No calf training](feedback-no-calf-training.md) — no calf work of any kind, incl. bodyweight/soleus raises in mobility and prehab (low insertions, legs bulky, wants them smaller); running + plyos carry the Achilles role
- [No box jumps](feedback-no-box-jumps.md) — default the plyo slot to light jump squats (or broad jumps / A-skips)
- [Strength rotation: two-session lookback](feedback-strength-rotation-two-session-lookback.md) — rotate non-fixed slots against the last TWO same-type sessions
- [Core needs ≥2 options per pattern](feedback-core-needs-two-options-per-pattern.md) — a one-option pattern gets dropped, not rotated; select core by pattern (anti-rotation / anti-lateral for runners)
- [Verify a load baseline before flagging a regression](feedback-verify-load-baseline-against-athlete.md) — Garmin pre-fills reps from the prescription; uniform reps = fiction; the athlete's account outranks the record
- [Re-derive, don't inherit](feedback-rederive-not-inherit.md) — rebuild the week's shape from rules + data each morning; a conservative default needs a reason too
- [Trailing-load check](feedback-trailing-load-check.md) — print a 7-day load ledger with the recovery trend before the readiness verdict
- [Soft markers — check anxiety first](feedback-soft-markers-check-anxiety.md) — long awake time on balanced HRV + normal deep sleep = rumination, not training fatigue
- [Quality session periodization](feedback-quality-session-periodization.md) — pick the rung from the ladder + phase week, not the athlete's phrasing
- [Pace-HR calibration](feedback-pace-hr-calibration.md) — quality paces come from his recent sessions at the target HR, never generic tables
- [Garmin easy paces work](feedback-garmin-easy-paces-work.md) — race predictions improved when easy days were genuinely easy; one quality a week; DSW only when it diverges
- [Walk recovery on intervals](feedback-walk-recovery-intervals.md) — walk, not jog; read end-of-rep max HR, not rep average
- [Benchmark on matched reps](feedback-benchmark-matched-reps.md) — compare repeat sessions on the warmed-up reps, not session means
- [Treadmill control run protocol](project-treadmill-control-run-protocol.md) — 5.0 km at a locked 8.6 km/h, 1%, treadmill mode, armband; tracked number is avg HR; never raise the belt
- [Treadmill run back-to-back with lift](feedback-treadmill-run-backtoback-with-lift.md) — a treadmill run + lift on one day is one gym trip; fuel accordingly
- [Easy run = one Garmin step](feedback-easy-run-single-step.md) — no warmup/cooldown blocks on easy or long runs
- [Garmin on-watch strength loads](feedback-garmin-onwatch-strength-loads.md) — the watch hides structured weights; put loads in the step name/description
- [Garmin watch = offsite reference](feedback-garmin-watch-offsite-reference.md) — execution data on the watch; nutrition never
- [Ask for the exact location](feedback-ask-exact-location.md) — get the exact town before building routes; a region menu is not an answer

## Nutrition

- [Tracking & adherence](feedback-tracking-adherence.md) — weighs food, follows plan days exactly, logs nothing digitally; a stall is an off-plan or TDEE question
- [Prefers activity over food cuts](feedback-prefers-activity-over-food-cuts.md) — but NEAT is opportunistic and "more cardio" never means more hard running
- [Lower tiers as social buffer](feedback-lower-tiers-as-social-buffer.md) — build at +300 not +400; the build's weight trend already prices in social evenings, so the cut must not subtract them twice
- [Adjust day on skipped session](feedback-adjust-day-on-skipped-session.md) — re-tier the day's food down from carbs, hold the floors, **name the feed to cut** (left alone he deletes the afternoon snack)
- [Living nutrition table](feedback-living-nutrition-table.md) — on `/log meal`, overwrite the eaten row, re-tune the rest to hold the tier; a Projected row over Expected is a defect when written
- [Check time before nutrition](feedback-check-time-before-nutrition.md) — get the real local time before sequencing feeds
- [No single dominant feed](feedback-no-single-dominant-feed.md) — meals ~450–750, snack ~250–300, protein boluses ≤~45 g; spread a shortfall, don't dump it into dinner
- [Starch at both main meals](feedback-starch-at-both-main-meals.md) — shrink rice/potato, never delete it
- [Fat floor — never a pourable drizzle](feedback-fat-floor-lean-fish-dinners.md) — build fat into the dish and bank it in the at-home meals; assume one meal gets swapped
- [Solid snack, not a shake](feedback-solid-snack-over-shake.md) — afternoon anchor is ~200 g skyr + whey stirred in + fruit
- [Post-dinner dessert for evening hunger](feedback-post-dinner-snack-hunger.md) — evening is the hard window; small afternoon snack, dessert after dinner
- [Post-lunch sweet = craving control](feedback-fruit-after-lunch-craving-control.md) — 0-cal gelatin since 2026-08-06, carbs folded into lunch; post-lunch slot only
- [No breakfast before a *quality* run](feedback-no-breakfast-before-run.md) — banana + coffee before quality/long; easy runs tolerate breakfast; on a pre-lunch double breakfast fuels the lift
- [Oats fruit mix-in](feedback-oats-fruit-mix-in.md) — reduced oats + mango or strawberries, never banana/apple
- [No grams for eggs](feedback-no-grams-for-eggs.md) — eggs and whites as counts, never grams
- [Rice served with beans](reference-rice-served-with-beans.md) — count ~80 g beans and ~2.4 g oil fat per 100 g cooked rice
- [Mythos Ligeiro yogurt](reference-mythos-ligeiro-yogurt.md) — protein-weak (5.3 g/100 g); buy on the protein number
- [Daily supplement → daily anchor](feedback-daily-supplement-daily-anchor.md) — hang daily doses on a fixture that never moves; BIA muscle mass is creatine-sensitive
