# Report Note - Add Notes to Daily Report

Add explanatory notes to today's daily report.

## Usage
```
/report-note [text]
```

## Examples
- `/report-note "Skipped dips due to shoulder discomfort"`
- `/report-note "Had to cut workout short - baby woke up"`
- `/report-note "Felt very strong today, could increase weight next session"`
- `/report-note "Late dinner due to work meeting"`
- `/report-note "Increased weight on bench press - form felt good"`

## Function
1. Find or create today's daily report
2. Add note to Notes section
3. Include timestamp if multiple notes added
4. Preserve existing notes

## Requirements
- Append to existing notes section
- Use bullet points for multiple notes
- Keep context brief but informative
- Useful for explaining protocol deviations, feelings, observations
- Track factors affecting performance or adherence
