# Adjust Protocol - Suggest Protocol Modifications

Suggest protocol modifications based on recent performance and feedback.

## Usage
```
/protocol-adjust
```

## Function
1. Analyze recent training and nutrition data
2. Identify patterns and plateaus
3. Reference current research for optimizations
4. Suggest evidence-based adjustments
5. Consider life constraints and sustainability

## Output Format
```
## Protocol Adjustment Recommendations

### Analysis Summary
**Training Trends:** [Progression/plateau patterns]
**Nutrition Adherence:** [Consistency patterns]
**Recovery Indicators:** [Sleep/energy patterns]
**Life Factors:** [Schedule disruptions/family impact]

### Recommended Adjustments

**Training Modifications:**
- [Specific exercise/weight/volume changes]
- [Rationale based on performance data]

**Nutrition Optimizations:**
- [Meal timing/macro adjustments]
- [Practical improvements]

**Schedule Refinements:**
- [Timing adjustments for better adherence]
- [Family integration improvements]

### Implementation Plan
**Week 1:** [Initial changes]
**Week 2-3:** [Progressive adjustments]
**Monitoring:** [Key metrics to track]

**Research References:** [Supporting evidence for changes]
```

## Requirements
- Base on actual performance data from reports
- Reference current evidence and research
- Consider real-world constraints
- Provide progressive implementation plan
- Maintain focus on body recomposition goals
